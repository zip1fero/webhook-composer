# Webhook Composer

A tool for sending messages and embeds to a Discord channel via webhook.

## Features
- Send plain text messages or full embeds (title, description, color, images, fields)
- Live preview that mirrors what the actual Discord message will look like
- No server or installation needed — runs entirely in the browser

## Usage
1. Open `index.html` (or the public GitHub Pages link)
2. Paste your channel's webhook URL
3. Write a message and/or build an embed
4. Hit send
